# Graduation book

The book is written **with** the project, not at the end. Two files, two jobs:

| File | What it is |
|---|---|
| [`Graduation_Project_Book_Template.docx`](Graduation_Project_Book_Template.docx) | **Write here.** Copy it, rename it to your project, and fill the gray text. Formatting, numbering, and the table of contents are already done. |
| [`Graduation_Project_Book_Guide.pdf`](Graduation_Project_Book_Guide.pdf) | **Read this.** What to write in every section, how to add figures and tables, references, and the checklist before you submit (Arabic). The `.docx` is the same guide. |

> الدليل للقراءة بس، والكتابة كلها في ملف الـ Template. افتحوا الاتنين جنب بعض.

Rules that matter most:

- Use **Microsoft Word** (desktop). Google Docs and LibreOffice break the figure numbers and the table of contents.
- Never type numbers for headings, figures, or tables. Before every PDF: **Ctrl+A, then F9**.
- **No code inside any chapter.** Code goes only in the appendix, and only for something you created that is entirely new.
- At every milestone, put the current book here as `docs/book/<project-name>-book.pdf` (and the `.docx`).
